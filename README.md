# BarberFlow 💈 - Plataforma de Gestión para Barberías

Sistema integral de gestión operativa y control para barberías y salones masculinos. Diseñado para usarse de forma directa sin registros complicados.

## 🚀 Características Principales

- 📅 **Agenda de Turnos en Vivo:** Citas del día, estados en tiempo real (*En Silla, Cobrado, No Asistió*) y turnos manuales.
- 🔗 **Link de Reservas para Clientes:** Link directo personalizable para compartir en redes sociales y WhatsApp.
- 💰 **Caja & Punto de Venta (POS):** Arqueo en tiempo real por Efectivo, Tarjeta y Transferencia/QR, venta de productos y registro de egresos.
- ✂️ **Comisiones Automáticas:** Cálculo exacto de pago a cada barbero y ganancia del local según porcentajes.
- 👥 **Directorio de Clientes (CRM):** Historial de visitas, total consumido, notas de corte y enlace directo a WhatsApp.
- 💈 **Gestión de Barberos:** Alta y baja de miembros del equipo con su % de comisión.
- ⚙️ **Personalización Total:** Nombre del local, dirección, WhatsApp, moneda y catálogo de servicios con precios y duración.
- 💾 **Respaldo de Datos:** Exportación e importación en formato JSON.

## 🛠️ Tecnologías

- **HTML5 & CSS3** (Vanilla Design System, Dark & Gold Barber Theme)
- **JavaScript Moderno** (ES6+ sin dependencias pesadas)
- **Almacenamiento:** LocalStorage con persistencia reactiva.

## 📦 Instalación y Uso

Solo abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Safari, Firefox).
